## 帮助与文档

mcmc3r 实验台是 **mcmc3r** R 包的独立、非官方图形界面。它封装三类工作流：校准分布探索、MCMC 输出汇总、边际似然估计。计算由服务器上的 `mcmc3r` 完成；图形界面负责校验、双语文案、主题与可复现导出。

## 快速开始

1. 在顶部导航中选择模块。
2. 输入参数或上传文件。数据模块均提供示例数据。
3. 点击 **运行**，查看结果，然后下载 CSV、PNG、PDF 或 ZIP 打包结果。

本应用为公开应用，托管在 Posit Connect Cloud。免费套餐提供公开内容与 1 GiB 部署包上限；计算与用量限制取决于账户套餐，用量配额目前只统计、不强制中断。应用在空闲一段时间后首次访问可能需要冷启动。请勿上传机密、个人或受管制数据；敏感工作请在本地运行源代码。

## 校准分布探索

校准分布探索用于计算 MCMCtree 使用的校准分布：

- **L（最小边界）**：位于 `tL` 以上的截断柯西分布。
- **B（联合边界）**：`tL` 与 `tU` 之间的上下软边界。
- **U（最大边界）**：位于 `tU` 的软上边界。

参数说明：

| 参数 | 含义 | 范围 |
|---|---|---|
| `tL` | 最小年龄（Ma） | > 0 |
| `tU` | 最大年龄（Ma），仅 B | > `tL` |
| `p` | 截断柯西分布的众数参数 | ≥ 0 |
| `c` | 截断柯西分布的尾部衰减 | > 0 |
| `pL` | 下尾概率 | 0 < `pL` < 1 |
| `pU` | 上尾概率，B 与 U | 0 < `pU` < 1，且 `pL + pU` < 1 |
| X 轴上限 | 绘图范围（Ma） | 留空 = 自动（97.5% 分位数，再扩展 15%） |
| 采样点数 | 曲线分辨率 | 100–5000 |
| 分位数概率 | 表中显示的概率 | 0.001–0.999 |

密度与累积概率由 `mcmc3r::dL`、`dB`、`dU`、`pL`、`pB`、`pU` 计算；分位数使用 `qL`、`qB`、`qU`。当形状参数小于 1 时，截断分布在 `x = 0` 处可能出现无穷密度；此类值在图中裁剪，在 CSV 中留空。MCMCtree 语法使用表单中的同一组数值生成，例如 `L(10, 0.1, 1, 0.025)`。

## MCMC 汇总

上传 MCMCtree 或 BPP 生成的 `mcmc.txt`。分隔符默认自动识别；若解析错误，可手动选择空白、制表符或逗号。超宽表格可隐藏列预览。应用使用严格前缀识别时间列：

- MCMCtree：`t_`
- BPP：`tau_`

只有名称以该前缀开头的列会被汇总，从而避免误选 `theta_`、`mu_t_` 等非时间列。任一被选时间列含 `NA`、`NaN` 或无穷值的行会被删除并报告。汇总结果包含均值、中位数、2.5% 与 97.5% 分位数以及样本数。

对多列输入，计算结果与 `mcmc3r::mcmc.sum` 等价；同时处理了上游辅助函数会报错或返回空表的单列、缺失值、无时间列情形。参数名保持文件中的原始名称。

## 边际似然

提供两种方法：

- **步进采样法**（`stepping.stones`）：beta 必须满足 `0 ≤ beta < 1`、严格递增且不含 1。beta = 0 会按上游 `make.bfctlf` 的约定写为 `1e-300`。函数内部会自动追加 1。
- **高斯–勒让德求积**（`gauss.quad`）：beta 必须满足 `0 < beta < 1`、严格递增，并与 `make.beta(n, "gauss-quad")` 在 `1e-6` 容差内一致。

支持两种输入结构：

- **ZIP 压缩包（推荐）**：根目录包含 `beta.txt` 与编号目录 `1/mcmc.txt` … `n/mcmc.txt`。允许外层再套一个目录，例如 `demo/beta.txt` 与 `demo/1/mcmc.txt`。
- **单独文件**：选择链文件；除非使用生成的 beta 值，否则需另行上传 `beta.txt`。链文件按文件名中的第一个数字进行自然排序。

每个链文件必须包含 `lnL` 列，且至少有两个有限值。图形界面会把单列 `lnL` 写入隔离的运行目录，并在 `withr::with_dir()` 中调用上游函数。上游函数使用相对路径，因此在共享 Shiny 进程中必须隔离工作目录。对数边际似然与标准误直接来自 `mcmc3r`。

若上游近似标记 `var(r_k)/r_k² > 0.1`，标准误会标记为不可靠。这是警告，不是失败。建议延长链或调整 beta 安排。

## 文件格式

### mcmc.txt

第一行为表头。支持空白、制表符或逗号分隔，至少两行数据，允许额外列，编码为 UTF-8 或 ASCII。

```
Iteration   lnL        t_1       t_2
1           -12345.6   10.20     5.10
2           -12344.9   10.31     5.05
```

BPP 输出通常使用 `tau_` 而非 `t_`，且可能没有迭代列。

### beta.txt

每行一个数值，无表头，严格递增，不含 1。

```
0.0000
0.0625
0.2500
0.5625
```

### 链结果 ZIP

```
demo/
├── beta.txt
├── 1/mcmc.txt
├── 2/mcmc.txt
├── 3/mcmc.txt
└── 4/mcmc.txt
```

绝对路径、`..` 路径、加密压缩包、文件数过多或压缩比异常的压缩包会被拒绝。应用不会按压缩包内的路径解压；仅将白名单成员复制到经过清理的目标位置。

## 错误码

错误与警告使用稳定错误码，每个错误码都有双语说明与建议操作。

| 错误码 | 含义 | 处理建议 |
|---|---|---|
| CAL-001 | `tL ≤ 0` | 输入大于 0 的最小年龄 |
| CAL-002 | `c ≤ 0` | 输入大于 0 的尾部衰减 |
| CAL-003 | `p < 0` | 输入非负的众数参数 |
| CAL-004 | `pL` 不在 (0,1) | 使用例如 0.025 的概率 |
| CAL-005 | `tU ≤ tL` | 增大 `tU` 或减小 `tL` |
| CAL-006 | `pU` 非法或 `pL + pU ≥ 1` | 保证两个尾部概率有效且和小于 1 |
| CAL-007 | 分位数概率过极端 | 使用 0.001 到 0.999 之间的概率 |
| CAL-008 | X 轴上限非法 | 输入正数或留空 |
| CAL-009 | 采样点数超出 100–5000 | 调整采样点数 |
| CAL-010 | 分位数数值求解失败 | 调整参数或概率 |
| CAL-011 | 边界处密度/累积概率为无穷 | 属正常情形；图中裁剪、CSV 留空 |
| CAL-012 | 未选择密度或累积概率 | 至少勾选一项 |
| MCMC-001 | 文件无法解析 | 检查分隔符与表头 |
| MCMC-002 | 空文件或只有表头 | 提供至少两行数据 |
| MCMC-003 | 无时间列 | 使用 `t_`/`tau_` 或自定义前缀 |
| MCMC-004 | 时间列非数值 | 清理数据 |
| MCMC-005 | 文件过大或行数超限 | 抽稀或拆分文件 |
| MCMC-006 | 列名重复 | 使表头唯一 |
| MCMC-007 | 非有限值过多 | 检查链数据 |
| MCMC-008 | 已删除含 NA/NaN/Inf 的行 | 信息性警告 |
| ML-001 | beta.txt 不是数值 | 每行提供一个数值 |
| ML-002 | beta 越界或包含 1 | 遵循方法对应的范围 |
| ML-003 | beta 非严格递增 | 排序或重新生成 |
| ML-004 | beta 数量 ≠ 链数量 | 对齐文件与 beta |
| ML-005 | 缺少 `lnL` 列 | 使用 MCMCtree/BPP 输出 |
| ML-006 | `lnL` 含非有限值 | 检查链 |
| ML-007 | 链样本少于两行 | 提供非空链 |
| ML-008 | 高斯–勒让德 n > 256 | 减少 beta 点数 |
| ML-009 | beta 与高斯–勒让德规则不匹配 | 使用 `make.beta` 生成 |
| ML-010 | 上游计算失败 | 查看详情并报告错误码 |
| ML-011 | beta 点数或生成参数超出范围 | 减少点数并使用正指数 |
| FILE-001 | 文件或压缩包过大 | 减小输入 |
| FILE-002 | ZIP 结构不安全或不完整 | 按规定重新打包 |
| FILE-003 | 扩展名不受支持 | 使用 `.txt`、`.tsv`、`.csv` 或 `.zip` |
| FILE-004 | ZIP 文件数过多或压缩比异常 | 仅打包所需文件 |
| SYS-001 | 未预期错误 | 复制诊断信息并提交 issue |
| SYS-002 | 内存或资源不足 | 减小输入 |
| SYS-003 | 计算超时 | 拆分任务 |

诊断信息包含错误码、模块、简短说明、技术详情、应用版本与上游 commit，不包含文件内容或完整路径。

## 故障排查

- **应用较慢或不可用**：Connect Cloud 以单实例运行应用，空闲一段时间后的首次请求可能需要冷启动；计算与用量限制取决于账户套餐。请稍后重试或在本地运行。
- **中文导出图显示方块**：应用启动时加载随包字体；若自建部署删除了 `www/fonts`，请恢复字体并重启。
- **ZIP 被拒绝**：检查是否包含 `beta.txt`、编号目录是否连续、每个目录是否有 `mcmc.txt`，以及是否存在绝对路径或 `..` 路径。
- **结果与直接调用 R 不同**：确认 beta 值与链顺序一致，并确认边际似然函数只使用 `lnL` 列。
- **标准误被标记为不可靠**：上游 delta 近似检测到较大的方差比。请延长链或增加 beta 点数。
