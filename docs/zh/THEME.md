## 适用范围

明暗两套主题覆盖页面、页头、卡片、表单、按钮、表格、代码块、提示条、模态框、文件输入、页脚、绘图与导出。主题与语言相互独立，四种组合都必须可用。

## 设计语言

界面遵循 `design-md/wired/DESIGN.md` 的 Wired 编辑式系统：

- **纸墨关系。** 亮色是 `gray 1` 纸面（`#FCFCFC`）配 `gray 12` 墨色（`#202020`），暗色是 `gray 1`（`#111111`）配 `gray 12`（`#EEEEEE`）。颜色用于标注而非装饰：蓝色标注链接与聚焦，红、琥珀、绿只标注状态。
- **主色即墨色。** `primary` 亮色为 `#202020`、暗色为 `#EEEEEE`，用于运行按钮与校准主曲线；蓝色只留给链接、聚焦环与绘图系列。
- **发丝线与零圆角。** 所有边框、分隔线、表格行线与区块线都是 0.5px。没有圆角、没有投影，也没有卡片左缘的彩条。
- **三种字体、四档字号。** 标题用显示衬线，正文用阅读衬线，控件与数据用界面无衬线。字号只有 40 / 22 / 15 / 12 px，层级靠字体、字重、颜色与间距建立，不靠新增字号。
- **操作句首大写，只有结构用大写。** 按钮、字段标签、区块小标题、表格与提示均用句式大小写、不加字距；只有顶部导航与页脚栏目标题用 12px 大写。技术标识保持原写法，`tL`、`pL`、`t_`、`tau_` 不会变形。
- **文案不承担装饰。** 不用 `·` 作分隔符；不复述控件本身已显示的信息；工作台不写实现细节。只有用户无法从控件推断的规则才保留为注释。
- **动效只保留颜色。** 过渡是颜色与边框的 250ms ease-out，没有缩放、滑入或淡入，页面切换直接跳转。唯一例外是运行中按钮内的转圈，它报告状态。

## 颜色令牌

语义令牌定义在 `R/fct_theme.R`（供绘图与导出），并以 CSS 变量镜像到 `www/css/app.css`。两者必须一致，CSS 取值也是测试的一部分。页脚一对（`--footer-bg`、`--footer-fg`）只存在于 CSS，因为绘图与导出不画页脚。

色板使用 Radix UI Colors，按 step 职责分配：1–2 为页面与表面填充，3–5 为组件填充，6–8 为边框，9–10 为实心填充，11–12 为高对比文本。只引入组件真正用到的 step。两处偏离是有意的：`border_strong` 取 step 9，因为 step 8 对表面仅 1.9:1，而标识控件边界需要 3:1（WCAG 1.4.11）；`divider` 取 step 6（Radix 的分隔线角色），把 step 7 留给边框。

## 字阶

| 角色 | 字号 | 字体 | 用途 |
|---|---|---|---|
| 展示 | 40px | 显示衬线 | 仅页面标题（`h1`） |
| 标题 | 22px | 显示衬线 | 面板标题、关于页卡片 |
| 正文 | 15px | 长文用阅读衬线，控件用界面无衬线 | 说明文字、结果 |
| 标签 | 12px | 界面无衬线；仅导航与页脚栏目用大写 | 导航、按钮、字段标签、列头、注释 |

界面不含小于 12px 的文字。15px 以下若需区分，改用字重（400/500/600）、`text_muted` 或字距，不新增字号。

## 布局与对齐

- **单一外壳。** `--shell: 1240px` 与 `--gutter: 32px` 让页头、页面标题、工作台与页脚落在同一左缘，任何组件都不再自定义页宽。
- **两列一线。** 工作台为 `348px` 控件列、`64px` 间隔、自适应结果列。竖分隔线是画在间隔正中的 0.5px `::after` 边框，两列都不占用它。
- **光学对齐。** 控件文字起于外壳左缘，分隔线相隔半个间隔；运行行吸附在 `--header-height + 10px`，主操作不会被页头遮住。
- **内嵌块按一级内缩对齐。** 圆角为零，因此不存在同心圆角换算；内嵌面板以 `--space-2` 内缩，边缘与外层容器对齐。
- **统一的度量。** 成段文字止于 15px 正文的 `36em`（540px，约 70 字符/36 汉字）。区块线、列表与表格同此宽度，帮助页所有内容收在同一右缘。
- **成组控件共用一个外框。** 文件上传、复选框与分段切换只在整组外围画一圈 0.5px 边框，内部接缝也是 0.5px，不与外框叠成双线。
- **页内目录。** 目录编号采用悬挂缩进，换行后与文字对齐而不是缩到编号下方；移动端折叠为带箭头的展开项。

## 初始化（无闪烁）

`<head>` 中的内联脚本在首帧之前执行：

1. 读取 `?theme=`、`localStorage["mcmc3r-bench-theme"]` 与 `prefers-color-scheme`。
2. 写入 `<html data-bs-theme="light|dark">`、`theme-dark` 类与 `data-theme`。
3. 更新 `<meta name="theme-color">`（亮色 `#FCFCFC`，暗色 `#111111`）。

服务端渲染的 HTML 不硬编码亮色背景或文字颜色。

优先级：URL 参数 > 已存偏好 > 系统偏好 > 亮色。

## 切换

页头按钮更新属性、写入偏好、刷新 `aria-label` 与 `aria-pressed`，并发送 `Shiny.setInputValue("theme", value)`。图标与整页重绘本身就是反馈，因此切换不弹提示。服务端保留一个 `reactiveVal` 供绘图与导出使用。切换不重载页面、不重置输入、不重算上游结果。

## 绘图

`fct_plots` 接收 `theme` 并调用 `plot_colors()`。base graphics 设置 `par(bg, fg, col.axis, col.lab, col.main, col.sub)`，网格线取 `--plot-grid`。图直接画在页面底色上，背后没有白色卡片，`plotOutput` 容器也不设固定背景。

- **标注画在数据区之外。** 分位数百分比置于上边距，与各自的点线对齐；两个数值过近时，后一个上移一行。图题独占更上面一行，曲线、网格与标题都不会被压住。
- **一条曲线一种画法。** 密度为实线墨色；密度与 CDF 同框时，CDF 改为淡灰虚线并使用右侧竖排轴标题，标题变为“校准分布”。不设图例，轴标题已经说明各自含义。
- **标题随内容。** “校准密度”“累积分布”或“校准分布”。

主题切换时，图与表使用内存中的结果重新渲染。字体由 `sysfonts` 与 `showtext` 注册一次；PNG 用 cairo 设备，PDF 用 cairo_pdf，DPI 按导出设置调整。

## 表格

DT 重排为数据表：透明背景、0.5px 行线、无斑马纹、12px 淡色列头（保持原大小写）、`surface2` 悬停。行距 `8px 12px`，十行预览读成一块而不是十张卡片。数字右对齐，列头与数字共用同一右缘；排序箭头只在悬停时出现，不在表头印三个三角。每页条数选择器是 32px 输入框，与其它控件同一发丝线。分页写成文字，当前页加下划线，而不是一排带框方块。表格宽于所在列时自己横向滚动（表头与表体同步），整页不会横向滚动。暗色覆盖每个单元格、控件与空态颜色，不留白色单元格。

## 导出

| 场景 | 默认 | 可选项 |
|---|---|---|
| 屏幕绘图 | 跟随应用主题 | — |
| PNG/PDF | 打印（亮色）主题 | 跟随屏幕主题 |
| CSV | 无主题 | — |

主题与分辨率收在导出按钮下方的“导出选项”折叠层里，因为默认值已覆盖绝大多数运行。导出始终由结果对象按所选主题重新生成，不复用屏幕位图。元数据记录 `screen_theme` 与 `export_theme`。

## 打印

`www/css/print.css` 必须重置**每一个**带暗色取值的令牌，包括各个 `*_soft` 表面、`tile_*` 填充，以及只存在于 CSS 的页脚一对。漏掉一个，暗色模式打印就会在纸面上出现深底深字。`tests/testthat/test-frontend-design.R` 会校验色板；新增令牌时同步评审打印样式。

## 无障碍

- 正文对比度 ≥ 4.5:1（主文本目标 ≥ 7:1）。
- 聚焦环在两种底色上都可见，且从不移除。
- 状态用图形符号加文字表达，不只靠颜色。
- `prefers-reduced-motion` 无需额外分支：过渡只剩颜色与边框。
- 主题按钮有可访问名称与 `aria-pressed`。
- 两套主题用同一套键盘与读屏流程走查。
