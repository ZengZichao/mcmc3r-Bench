## mcmc.txt

### 要求

- 第一行为表头。
- 支持空白、制表符或逗号分隔。
- 至少两行数据。
- UTF-8 或 ASCII；不支持 GBK，请先转换为 UTF-8。
- 数值列不带单位。

MCMC 汇总要求至少一个时间列（MCMCtree 为 `t_`，BPP 为 `tau_`）。边际似然要求
`lnL` 列，并忽略其他列。允许 `mu`、`sigma2`、`r_g1_*` 等额外列。

### 示例：MCMCtree

```
Iteration   lnL        t_1       t_2       t_3
1           -12345.67  10.20     5.10      2.30
2           -12344.91  10.31     5.05      2.28
3           -12346.02  10.25     5.12      2.31
```

### 示例：BPP

```
tau_1   tau_2   tau_3   lnL
10.20   5.10    2.30    -12345.67
10.31   5.05    2.28    -12344.91
10.25   5.12    2.31    -12346.02
```

### 边界情形

- 接受单个时间列。
- 任一被选时间列含 `NA`、`NaN`、`Inf` 或 `-Inf` 的行会被删除并报告（MCMC-008）。
- 重复列名会被拒绝（MCMC-006）。
- 无时间列的文件会被拒绝（MCMC-003），即使包含 `lnL`。
- 只有表头的文件会被拒绝（MCMC-002）。

## beta.txt

### 要求

- 每行一个数值，无表头。
- 严格递增。
- 步进采样：`0 ≤ beta < 1`。写入临时文件时，0 会转换为 `1e-300`。1 由函数内部
  追加，文件中不得包含 1。
- 高斯–勒让德：`0 < beta < 1`，并与 `make.beta(n, "gauss-quad")` 在 `1e-6` 内一致。

### 示例

```
0.0000
0.0625
0.2500
0.5625
```

## 边际似然 ZIP

### 结构

```
demo/
├── beta.txt
├── 1/mcmc.txt
├── 2/mcmc.txt
├── 3/mcmc.txt
└── 4/mcmc.txt
```

- `beta.txt` 与编号目录可位于压缩包根目录，或外层套一个目录。
- 目录名必须是自 1 开始的连续整数。
- 每个目录必须包含带 `lnL` 列的 `mcmc.txt`。
- 无关文件会被忽略，但计入文件数上限。
- beta 数量必须等于目录数量。

### 拒绝的压缩包

- 绝对路径、`..` 路径或反斜杠分隔符。
- 加密压缩包。
- 文件数超过 500。
- 解压后超过 200 MB。
- 压缩比超过 100:1。

应用不会按压缩包内路径解压。它先校验条目列表，仅把白名单成员复制到经过清理的目标
位置，且绝不写出会话目录之外。

## 单独的链文件

每个 beta 点选择一个 `mcmc.txt`。文件按文件名中的第一个数字排序；无数字时按字典序。
请另行上传 `beta.txt`，或在应用内生成 beta 值。数量必须与文件数一致。

## Newick 树（v0.2.0 计划）

Newick 树将用于 densitree 与 multiPhylo 模块。树必须 rooted 且严格二叉，末端标签
必须与 MCMC 输出中的名称一致。不支持 NEXUS。

## 输出 CSV

### 校准

```
x,density,cdf
0.000000,NA,0.000000
0.973709,0.000123,0.025000
...
```

### MCMC 汇总

```
parameter,mean,median,ci025,ci975,n
t_1,10.25,10.24,9.80,10.70,8000
t_2,5.10,5.09,4.85,5.35,8000
```

### 边际似然总表

```
model,method,logml,se,n_beta,se_reliable,beta_zero_converted,computed_at,app_version,upstream_version,upstream_sha
demo,step-stones,-1278.699,0.769756,5,FALSE,1,...
```

### CSV 规则

- UTF-8、逗号分隔、首行表头。
- 数值不加千分位；缺失值为空字符串。
- 使用稳定的英文列名。
- 用户提供的字符串若以 `=`, `+`, `-`, `@` 开头，前置单引号以防公式注入。
- 通过元数据列或 `metadata.json` 记录版本与主题。
