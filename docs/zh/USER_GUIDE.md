## 界面概览

顶部包含品牌、五个页面按钮、语言切换器与亮/暗主题切换器。顶部下方是公开数据提示。

## 校准分布探索

### 用途

在编写控制文件之前，探索 MCMCtree 使用的校准分布。页面用同一组参数计算密度、
累积概率、分位数与 MCMCtree 语法。

### 参数

- **校准类型**：`L`（最小边界）、`B`（联合边界）、`U`（最大边界）。
- **`tL`**：最小年龄（Ma）；L 与 B 需要。
- **`tU`**：最大年龄（Ma）；B 与 U 需要。
- **`p`、`c`**：截断柯西分布的众数与尾部衰减参数（L）。
- **`pL`、`pU`**：下尾与上尾概率。
- **X 轴上限**：留空表示自动（当前分布的 97.5% 分位数，再放宽 15%）。
- **采样点数**：100–5000。
- **显示**：概率密度和/或累积概率。
- **高级 → 分位数概率**：逗号分隔的概率值。

修改参数后需点击 **运行**。结果不会自动重算；“显示”复选框只重绘已有曲线。

### 结果

- 密度与可选累积概率图，使用 base graphics 与当前主题绘制。
- 输入概率对应的分位数表。
- 带复制按钮的 MCMCtree 语法。
- 绘图数据表（前 500 行）与包含全部点的 CSV 下载。
- 导出控制：打印/屏幕主题、150/300 dpi PNG、PDF。

### 说明

在 `x = 0` 处，部分截断分布的密度为无穷大。此类值在图中裁剪、在 CSV 中留空，
并给出 CAL-011 警告。自动 X 轴上限基于 97.5% 分位数；对于重尾的 L 校准可能较宽，
可输入较小值获得更紧凑的图。

## MCMC 汇总

### 用途

汇总 MCMCtree 或 BPP 生成的 `mcmc.txt` 中的节点年龄。

### 载入数据

- 上传 `.txt`、`.tsv` 或 `.csv` 文件（最大 50 MB）。
- 分隔符可选择 **自动识别**、空白、制表符或逗号。
- 或点击示例按钮：*Microcebus* 与 *Hominids* 是使用 `tau_` 列的 BPP 示例；
  *Carnivores* 是使用 `t_` 列的 MCMCtree 示例。

文件会立即解析。诊断卡报告行数、列数与文件大小；**显示列预览** 控制前 20 列、前 10 行
的预览，超宽表格可取消勾选。

### 选择时间列

- **自动识别**：优先 `tau_`，其次 `t_`。
- 显式选择 `t_` 或 `tau_` 使用严格前缀。
- **自定义前缀**按字面匹配；正则元字符会被转义。

只有名称以该前缀开头的列会被汇总；`theta_`、`mu_t_` 等列会被忽略。

### 结果

- 每个参数的均值、中位数、2.5% 与 97.5% 分位数、样本数。
- 诊断：读取/使用/删除行数、非有限值单元格、时间列数、文件大小、分隔符。
- 使用稳定英文列名的 CSV 下载。

任一被选时间列含 `NA`、`NaN` 或无穷值的行会在汇总前删除，并通过 MCMC-008 警告
报告删除数量。若全部行被删除，则触发 MCMC-007。

### 说明

上游 `mcmc.sum()` 有三个边界情形，图形界面已显式处理：单列输入（`apply()` 会报错）、
非有限值（中位数会报错）、无时间列（上游返回 0 行）。图形界面直接计算等价汇总，
并在测试中与 `mcmc3r::mcmc.sum` 对比验证。

## 边际似然

### 用途

使用步进采样或高斯–勒让德求积估计一条或多条功率后验链的对数边际似然。

### 方法

- **步进采样法**：`beta.txt` 满足 `0 ≤ beta < 1`、严格递增；0 写为 `1e-300`；
  函数内部追加 1。
- **高斯–勒让德**：`0 < beta < 1`、严格递增，并与
  `make.beta(n, "gauss-quad")` 在 `1e-6` 内一致；界面中 n 最多 100（上游硬上限 256）。

### 链输入

- **ZIP 压缩包（推荐）**：`beta.txt` 加目录 `1/mcmc.txt` … `n/mcmc.txt`。
  允许外层再套一个目录。beta 值来自 ZIP。
- **单独文件**：每个 beta 点选择一个 `mcmc.txt`。可另行上传 `beta.txt`，或在应用内
  生成 beta 值。文件按文件名中的第一个数字自然排序。

每条链必须包含 `lnL`，且至少有两个有限值；其他列会被忽略。应用在隔离的运行目录中
写入仅含 `lnL` 的文件，并在临时工作目录中调用上游函数。

### 结果

- 汇总指标：logML、SE（含可靠性状态）、beta 点数、方法、模型名、时间戳。
- 平均 logL 随 beta 变化的图，可导出打印/屏幕主题的 PNG（150/300 dpi）与 PDF。
- 各 beta 明细表：beta、平均 logL、链行数、SE 警告标记。
- 总表 CSV、明细 CSV，以及包含两者与 `metadata.json` 的 ZIP 打包。

应用会报告 beta=0 的转换、上游警告与锁定的上游 commit。若标准误被标记为不可靠，
结果仍会显示，但带有警告标记。

### 资源上限

步进采样最多 50 个 beta 点，高斯–勒让德 100 个（上游硬上限 256），最多 50 个链文件。
总上传 100 MB，单文件 50 MB，ZIP 解压后 200 MB，文件数最多 500，压缩比不超过 100:1。

## 下载

文件名格式：

```
mcmc3r-bench_<模块>_<YYYYMMDD-HHMMSS>_<语言>_<主题>.csv|png|pdf|zip
```

CSV 为 UTF-8、逗号分隔、使用稳定的英文列名，并防止表格公式注入。PNG 与 PDF 默认
使用打印主题；选择“匹配屏幕主题”可导出暗色配色。边际似然打包中的 `metadata.json`
记录应用/上游版本与屏幕/导出主题，便于复现。

## 语言、主题与可访问性

- 语言切换即时更新所有静态文案，不刷新页面、不丢失输入。服务器渲染的结果会在客户端
  通知服务器新语言后刷新。
- 主题切换更新 CSS 变量，并重绘图与表，不重新计算上游结果。
- 两种偏好分别存储。首次加载时 `?lang=` 与 `?theme=` 覆盖已保存值。
- 应用支持键盘导航、可见焦点、ARIA 标签、页面切换与提示的实时播报，以及跳转链接。
- 图表均配有数据表；颜色不是唯一的信息载体。

## 重置与会话生命周期

每个模块都有 **重置** 按钮，仅清除该模块。上传文件与结果保存在服务器临时目录中，
会话结束时删除。应用不写数据库。
