## 摘要

托管版仅在当前会话内处理上传文件。文件保存在服务器临时目录，会话结束时删除。应用
不创建账号、不出售数据，也不会将上传数据用于分析或模型训练。本应用为公开应用：任何
获得链接的人都可以使用。请勿上传机密、个人或受管制数据。敏感数据请本地运行源代码。

## 收集的内容

- 上传文件：复制到会话专属临时目录，用于校验与计算。
- 内存状态：解析后的表格、参数与结果，仅在 Shiny 会话生命周期内保存。
- 访问日志：托管平台（Posit Connect Cloud）可能记录标准服务器日志，如 IP 地址、
  时间戳、请求路径与错误信息。

## 不收集的内容

- 不收集账号、邮箱、姓名或机构。
- 不使用第三方分析、广告或追踪脚本。
- 不使用追踪 cookie；`localStorage` 仅保存语言与主题偏好，不作为个人数据发送到服务器。
- 不建立持久数据库或跨会话缓存。
- 应用日志不记录上传文件内容。日志包含事件名、错误码、计数、耗时、版本与短会话令牌。

## 保留期限

- 临时文件：Shiny 会话结束时删除（`session$onSessionEnded`），或服务器进程回收时删除。
  会话可能因关闭标签页、平台设定的空闲超时或重新部署而结束。
- 日志：按托管平台政策保留。
- 仓库：不包含任何用户数据。

## 安全措施

- 上传按扩展名、大小、行数与 ZIP 结构限制。
- ZIP 条目先校验，仅复制到经过清理的目标位置；绝对路径、`..` 路径、加密条目与异常
  压缩比会被拒绝。
- 用户文本在 CSV 导出中防止公式注入，在 HTML 输出中防止脚本注入。
- 依赖通过 `renv` 锁定；工作流使用最小权限令牌。
- 诊断信息不包含文件内容或完整路径。

## 跨境传输

托管服务运行在 Posit（Connect Cloud）运营的基础设施上，可能位于你所在国家/地区之外。
若你受数据出境或数据本地化规则约束，请自行判断是否允许上传数据，或本地运行应用。

## 你的责任

- 不要向公开应用上传机密、个人或受管制数据。
- 不要上传你无权处理的数据。
- 不要尝试绕过限制、攻击服务或故意占用配额。
- 发表结果时请正确引用方法论文与上游包。
