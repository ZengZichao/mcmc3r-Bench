## Test pyramid

```
E2E / shinytest2      key paths, language/theme combinations
Integration           modules + fixtures + downloads
Unit                  services, validation, formatting, i18n, theme, files
```

## Running the tests

```bash
Rscript tests/testthat.R
Rscript dev/coverage.R
Rscript tests/shinytest2/run-tests.R
Rscript dev/i18n_check.R
Rscript dev/docs_check.R
Rscript dev/check_release.R
Rscript dev/benchmark.R
```

`dev/coverage.R` measures the four `services_*` files and fails below the 80%
release gate. The last local run (2026-10-24) reported **90.89%** service-layer
coverage: calibration 91.41%, marginal 92.62%, MCMC 81.82%, export 100%.

The test helper locates the app root, adds `.Rlib` if present, and sources
`global.R`. Fixtures are generated by `dev/make_fixtures.R` and kept under
`tests/fixtures/` (< 5 MB).

## Unit coverage

### Calibration

- Density and CDF compare with `mcmc3r::dL/dB/dU/pL/pB/pU` at `1e-8`.
- Quantiles compare with `qL/qB/qU` at `1e-6`.
- Syntax strings match MCMCtree notation.
- CAL-001 … CAL-009 validation codes.
- CAL-011 for infinite boundary density.
- Automatic x maximum is finite and positive.
- Malformed probability and x-maximum input.

### MCMC summary

- MCMCtree fixture matches `mcmc3r::mcmc.sum` at `1e-12`.
- BPP fixture auto-detects `tau_` and keeps original names.
- Single time column works.
- Non-finite rows removed and reported (MCMC-008).
- Missing time columns (MCMC-003), empty file (MCMC-002), duplicate names
  (MCMC-006), non-numeric columns (MCMC-004), all non-finite (MCMC-007), row
  limit (MCMC-005).
- Custom prefix is escaped and matched literally.

### Marginal likelihood

- Beta range, strict monotonicity, numeric readability, and method limits.
- Gauss–Legendre values match the n-point rule.
- ZIP structure and unsafe paths (FILE-002).
- Beta count mismatch (ML-004).
- Stepping-stones result matches the direct upstream call at `1e-10`.
- Gauss–Legendre result matches the direct upstream call at `1e-10`.
- `lnL` validation (ML-005, ML-006, ML-007).
- Beta=0 conversion and SE-warning flagging.

### Cross-cutting

- Formula injection escaping, natural ordering, filename template, number
  formatting, basename safety.
- i18n key uniqueness, non-empty values, error-code coverage, every `tr()` key
  used in `R/`, browser dictionary completeness, language parsing.
- Theme contrast (text ≥ 7:1 for body, ≥ 4.5:1 for muted text and buttons),
  distinct light/dark tokens, plot colours.
- Plot rendering for all calibration modes, marginal plots, PNG/PDF devices in
  both themes, and graphics-state cleanup.
- CSV/JSON/bundle export, metadata fields, and stable module data frames.
- ZIP safety (traversal, symlinks, file count, compression ratio), table
  parsing, preview conversion, sanitised upload paths.

## End-to-end tests

`tests/shinytest2/test-app.R` launches the app and checks:

1. Navigation and language switch (English ↔ Chinese).
2. Calibration defaults produce syntax, CSV, PNG, and PDF downloads.
3. Invalid `tL = 0` shows CAL-001 and the error translates after a language
   switch without losing state.
4. MCMC example summary, CSV download, a real BPP file upload, and MCMC-003
   for a file without time columns.
5. Marginal demo estimate plus summary, detail, PNG, PDF, and bundle downloads,
   after a beta-count mismatch (ML-004).
6. Bundle metadata records the selected `screen` export theme.
7. Unsafe ZIP is rejected with FILE-002.
8. Theme switch preserves results and updates `data-bs-theme`.
9. A 375 px viewport has no horizontal overflow.
10. The About page shows v0.1.0, the author and ORCID, MIT/CC BY 4.0, upstream
    0.6.0, and the unofficial disclaimer.

`tests/shinytest2/test-theme.R` opens fresh Chromote tabs to verify:

1. `?lang=zh&theme=dark` applies on first render, including server-rendered
   results.
2. Toggling language and theme persists to `localStorage` across reloads.
3. URL parameters override stored preferences.
4. All four language × theme combinations complete a calibration run without
   horizontal overflow.
5. The skip link targets `#main`, and the run button completes a calculation
   when activated with the keyboard (Enter).

`tests/shinytest2/run-tests.R` runs both files.

Screenshot baselines are not committed for every state; the release checklist
uses the eight-combination matrix instead.

## Visual and responsive checks

Viewports: 1440×900, 1024×768, 768×1024, 375×812. Combinations: 2 languages ×
2 themes × desktop/mobile = 8. Check empty, loading, success, warning, and error
states; tables scroll horizontally; buttons do not overflow; dark theme has no
white blocks; Chinese text is not truncated.

## Accessibility checks

- Keyboard: Tab order, Enter/Space activation, visible focus, skip link.
- Screen reader: form labels, error alerts with `role="alert"`, live region for
  page changes and toasts.
- Contrast: both themes, body text, buttons, errors, warnings, tables, focus
  rings.
- Charts have data-table alternatives; colour is not the only encoding.
- `<html lang>` and `data-bs-theme` update on switch.

## Security checks

- ZIP: `../`, absolute paths, symlinks, bombs, too many files, oversized
  decompression.
- Files: empty, header-only, binary disguised as text, oversized, non-UTF-8,
  duplicate headers.
- Text: `<script>`, `=cmd|' /C calc'!A0`, very long model names.
- Diagnostics contain no file contents or full paths; logs contain no data.
- `renv.lock` is consistent; no local-source package in the deployment.
- Licence, NOTICE, third-party notices, CITATION, and VERSION agree.

## Performance checks

`dev/benchmark.R` generates synthetic tables and records read, validate, compute,
and render times. Budgets:

| Scenario | Target | Limit |
|---|---|---|
| Calibration 1,000 points | < 300 ms | 1 s |
| Calibration 5,000 points | < 800 ms | 2 s |
| MCMC summary 100k rows | < 2 s | 5 s |
| MCMC summary 500k rows | < 8 s | 15 s |
| Marginal 10 beta × 20k rows | < 5 s | 15 s |
| Cold start (deployed) | < 30 s | 60 s |
| Peak memory (50 MB upload) | < 700 MB | 900 MB |
