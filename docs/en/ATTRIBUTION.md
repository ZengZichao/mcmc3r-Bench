## Upstream package

`mcmc3r` is an R package for working with MCMCtree and BPP. It is maintained by
Mario dos Reis and Sandra Alvarez-Carretero, with contributions from other
authors in the repository history. It is licensed under MIT, copyright 2017
Mario dos Reis.

## Wording rules

Use:

- "Built on `mcmc3r` by Mario dos Reis, Sandra Alvarez-Carretero, and contributors; this GUI is an independent, unofficial project by Zeng Zichao."
- "Unofficial GUI; not affiliated with or endorsed by the `mcmc3r` authors, MCMCtree, or BPP."

Avoid:

- "Official", "authorised", "collaboration", "joint development".
- Using upstream names, logos, portraits, or institutional marks as product
  branding.
